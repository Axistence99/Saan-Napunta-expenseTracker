Open Saan Napunta?

Install on Android

Use Chrome’s secure installation prompt to add the app.

  1. Open this page in Google Chrome.
  2. Tap Chrome’s three-dot menu.
  3. Select Install app or Add to Home screen.

Install on iPhone or iPad

  1. Open this page in Safari.
  2. Tap Share ↑.
  3. Scroll down and tap Add to Home Screen.
  4. Tap Add in the upper-right corner.

Install on this computer

Use the install icon in the browser address bar, or open the browser menu and choose Install Saan Napunta?.

Continue in browser

Installation is optional. Your expense data remains in this browser unless you enable sync.
